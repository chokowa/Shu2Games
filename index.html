          「僕も作れそう」と思える設計

          遊んだあとに、ゲームの仕組みを考えるヒントをまとめました。

          Gem Pop

          ランダムな場所にGEMを出す、下へ動かす、タップされたら点数を増やす、時間で終わる。

          Code Runner

          キャラを左右に動かす、落ちてくるブロックを取る、バグに当たると減点する。

          Passcode Crack

          4桁の数字を作る、入力を比べる、数字だけ正解と位置正解を数える。

          Cryptogram Lite

          同じ暗号記号を探す、見えている文字から穴の答えを推理する。
